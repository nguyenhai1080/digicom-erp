# Liberation Serif for input reconciliation

Unmodified Liberation Serif Regular, Bold and BoldItalic 2.1.5 from the upstream
[Liberation Fonts release](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5).
Archive: https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz

The accompanying `Liberation-LICENSE.txt` is the upstream SIL Open Font License.
These Times-compatible fonts support the owner's serif input reconciliation form
without bundling proprietary Windows fonts or extracting fonts from signed PDFs.
Noto Sans and its existing license remain in use by the other document renderers.
